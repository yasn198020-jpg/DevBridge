# DevBridge

Локальный помощник для автоматизации цикла разработки через обычный чат ChatGPT, Git и локальную сборку проектов Windows.

## Концепция

1. ChatGPT изменяет проект в GitHub через подключённую интеграцию.
2. В последнем сообщении ассистента публикуется команда DevBridge: `BUILD`, `WAIT`, `DONE` или `ABORT`.
3. Локальный агент проверяет выбранную ветку, получает изменения через обычный Git и запускает настроенный скрипт сборки.
4. При ошибке агент формирует диагностический отчёт и передаёт его в тот же чат.
5. Цикл повторяется до `DONE` или безопасной остановки.

## Принципы безопасности

- Никаких GitHub-токенов и GitHub API в DevBridge.
- Не выполнять pull при незакоммиченных локальных изменениях.
- Не переключать ветки и не изменять `main` автоматически.
- Останавливать цикл при конфликте, неизвестной команде или ошибке управления браузером.
- Ограничивать число итераций и сохранять журнал действий.

## Статус

Начальная точка репозитория. Реализация будет добавляться отдельными коммитами в рабочую ветку после первичной инициализации.
